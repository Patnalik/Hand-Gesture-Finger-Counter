# Hand Gesture Finger Counter

Скрипт на Python для распознавания кисти руки и автоматического подсчета количества согнутых/разогнутых пальцев в реальном времени с использованием MediaPipe и OpenCV.

## 💡 Как это работает

1. Программа захватывает видеопоток с веб-камеры и передает кадры в модель `MediaPipe Hands`.
2. На руку накладывается скелетная сетка (21 ключевая точка).
3. Для каждого из 5 пальцев рассчитывается евклидово расстояние по формуле $\sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$ между кончиком пальца и основанием сустава:
   * **Указательный:** точки `8` и `5`
   * **Средний:** точки `12` и `9`
   * **Безымянный:** точки `16` и `13`
   * **Мизинец:** точки `20` и `17`
   * **Большой:** точки `4` и `1`
4. На основе порога расстояния определяется, выпрямлен палец (`1`) или согнут (`0`).
5. Итоговая сумма поднятых пальцев выводится прямо поверх видео в окне OpenCV.

## 🛠️ Технологии

* **Python 3.x**
* **OpenCV** (`opencv-python`) — обработка видеопотока и визуализация текста/сетки.
* **MediaPipe** — детекция и трекинг ключевых точек кисти руки.
* **Math** — расчет расстояний в евклидовом пространстве.
